## Function Name

```python
math.degrees()
```

---

## Purpose

Describe what the function does.

_**converts angle x from radians to degrees**_


## Syntax

```python
math.degrees(x)
```

---

## Parameters

| Parameter | Required? (Yes/No) | Default Value | Expected Data Type | Description |
|-----------|---------------------|---------------|--------------------|-------------|
| x         | Yes                 | None          | int/float       |Angle in radians|

**_float- angles in degrees_**
