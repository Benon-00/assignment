# Function 42

## Function Name

```python
math.acos()
```

---

## Purpose

Describe what the function does.

_**Reurns the arc cosine of x, in radians, for x in range [-1,1]**_


## Syntax

```python
math.acos(x)
```

---

## Parameters

| Parameter | Required? (Yes/No) | Default Value | Expected Data Type | Description |
|-----------|---------------------|---------------|--------------------|-------------|
| x         | Yes                 | None          | int/float(-1 to 1)        |Value to compute arc cosine of|


> **Questions to answer**
>
> - Which parameters are required?
_**x is required**_
> - Which parameters are optional?
_**None is optional**_
> - What happens if you omit an optional parameter?
_**a TypeError occurs**_
> - What default value is used?
_**None**_

---

## Return Value

What does the function return?

**_float radians_**

## Example

import math

print(math.acos(-1))
print(math.acos(0))
print(math.acos(0.6754))
print(math.acos(1))
