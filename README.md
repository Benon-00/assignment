# Python Module Exploration Assignment

## Objective

Explore one Python Standard Library module and document five of its functions.

## Rules

- Do NOT use pandas.
- Choose only ONE module.
- Use the official Python documentation.
- Every example must run correctly.
- Commit your work regularly.
- Submit the GitHub repository link.

## Suggested Modules

- math
- random
- statistics
- datetime
- pathlib
- os
- csv
- json
- itertools
- collections
- decimal
- string


Submission

Students should:

Click Use this template (or fork the repository, depending on your workflow).
Rename your_module.md.
Complete the documentation.
Replace the example scripts.
Push their changes to GitHub.
Submit the repository URL.
